Software Systems Analysis & Design

Εφαρμογή μεθοδολογιών UML και Systems Analysis για τη μοντελοποίηση του ανθρώπινου σώματος ως οργανωτική δομή — από requirements capture μέχρι executable code με automated testing.

UML 2.x StarUML Python 3.10 pytest + GitHub Actions

📖 Σχετικά με την Εργασία

Η παρούσα εργασία αποτελεί το project του μαθήματος «Ανάλυση και Σχεδίαση Συστημάτων» (Spring 2025). Πραγματεύεται το ανθρώπινο σώμα ως οργανωτική δομή, εφαρμόζοντας μια σειρά από 6 διαδοχικά micro-tasks που καλύπτουν ολόκληρο το φάσμα των μεθοδολογιών ανάλυσης και σχεδίασης.

Reference Material: Britannica — Human Body — Η κύρια πηγή γνώσης για το domain.
Πλήρης υλοποίηση: Όλα τα 6 sub-projects έχουν ολοκληρωθεί — από requirements elicitation και UML modeling μέχρι executable Python code με passing unit tests σε GitHub Actions.

3 States

Initial → State 1 Είσαι σε εγρήγορση
State 2 Έτοιμος να μεταφέρει σήμα
State 3 Είσαι σε διαδικασία σκέψης
State 4 Έτοιμος για να δράσεις
State 5 Έτοιμος για άμεση δράση
Initial → Final: Από την αρχική κατάσταση ξεκινά η αλληλουχία. Η τελική κατάσταση (FinalState) βρίσκεται μετά την "Έτοιμος για άμεση δράση" — αφού ολοκληρωθεί η αντίδραση.

4 Transitions

From → ToTrigger / EventType
Είσαι σε εγρήγορση → Έτοιμος να μεταφέρει σήμα λήψη σήματος από ερέθισμα / μεταφορά_σήματος_για_επεξεργασία() Trigger
Έτοιμος να μεταφέρει σήμα → Είσαι σε διαδικασία σκέψης προώθηση στον εγκέφαλο[επεξεργασία] / επεξεργασία_&_αξιολόγηση_σήματος() Guard + Activity
Είσαι σε διαδικασία σκέψης → Έτοιμος για να δράσεις λήψη απόφασης / σκέψη_&_προετοιμασία_δράσης() Activity
Έτοιμος για να δράσεις → Έτοιμος για άμεση δράση ενεργοποίηση_αντανακλαστικού() Trigger
Έτοιμος για να δράσεις → FinalState λήψη κινητικής εντολής / εκτέλεση_μέσω_μυών_και_αδένων() Activity
Trigger, Guard, Activity: Όλα τα απαραίτητα elements είναι παρόντα — trigger (λήψη σήματος), guard ([επεξεργασία]), activity (επεξεργασία_&_αξιολόγηση_σήματος()).

5 Assumptions

01
Functions of the human body in case of a stimulus Επιλέχθηκε να μοντελοποιηθεί η συμπεριφορά του ανθρώπινου σώματος όταν δέχεται ένα ερέθισμα — από την αντίληψη μέχρι τη δράση.
02
Reflex vs Conscious Action Το μοντέλο διακρίνει δύο μονοπάτια: την άμεση αντίδραση (reflex) και την συνειδητή δράση (μέσω σκέψης και απόφασης).

2 Υλοποίηση

musculoskeletal_system.py

class Musculoskeletal_System:
    # Constructor
    def __init__(self, var01):
        self.cell_kind = var01

    # A simple function
    def move(self):
        if (self.cell_kind in ["muscles", "bones"]):
            return True
        else:
            return False

test_01.py

# import pytest
from musculoskeletal_system import Musculoskeletal_System

# Starting tests...
def test_01():
    a = Musculoskeletal_System("muscles")
    """ Check that move() == True """
    assert a.move() == True

def test_02():
    a = Musculoskeletal_System("bones")
    """ Check that move() == True """
    assert a.move() == True

def test_03():
    a = Musculoskeletal_System("nerves")
    """ Check that move() == False """
    assert a.move() == False
