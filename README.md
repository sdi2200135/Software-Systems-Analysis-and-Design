# Human Body — Software Systems Analysis and Design

Applying UML and systems analysis methodologies to model the human body as an organizational structure, using:
1. StarUML
2. Python

## 1. Project Overview

This project demonstrates fundamental Software Analysis and Design methodologies by treating the human body as a complex organizational system. The work is structured as a series of interconnected subprojects, each focusing on a different modeling perspective — from high-level requirements capture to detailed behavioral analysis and finally to executable code with validation.

Reference Material: [Britannica — Human Body](https://www.britannica.com/science/human-body)

## 2. Development Stack
- StarUML — employed for creating all UML artifacts (Use Case, Class, Sequence, and Statechart diagrams)
- Python 3 — utilized for implementation and unit test development
- Britannica — serves as the primary domain knowledge reference

## 3. Deliverables Breakdown
| # | Artifact | Methodology | Purpose |
|---|---|---|---|
| Sub01 | Use Case Model | UML Use Cases | Defines system boundaries and actor interactions (mammals, birds, fish) with the human body |
| Sub02 | Class Structure | UML Class Diagrams | Represents anatomical systems as object-oriented classes with properties, operations, inheritance, and associations |
| Sub03 | Interaction Flow | UML Sequence Diagrams | Documents the step-by-step messaging sequence during the respiration cycle |
| Sub04 | Behavioral States | UML State Machines | Captures the various states and transitions of a selected system component |
| Sub05 | Data Movement (Level 1) | DFD (Data Flow Diagram) | Illustrates how information flows through processes, external entities, and data repositories |
| Sub06 | Code + Testing | Python / unittest | Transforms one design model class into functional code accompanied by test cases |

3. Dynamic Modeling — sequence interactions, state transitions, and combined interaction fragments
